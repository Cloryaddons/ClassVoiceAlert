# Licensing decision

The repository intentionally ships without a `LICENSE` file until the maintainer chooses one.

If a public GitHub repository has no explicit software license, default copyright rules apply. People can view/fork it under GitHub's platform terms, but you have not generally granted them permission to reproduce, distribute, modify or create derivative works outside those terms.

Before you want community redistribution/contributions, choose a license deliberately.

Common options to evaluate:
- **MIT**: very permissive; reuse/modification/distribution allowed with copyright/license notice.
- **GPL-3.0**: copyleft; distributed derivative works must preserve GPL terms/source obligations.
- **No license for now**: useful while the repository is primarily your own maintenance source of truth.

For the first upload, using a **Private** repository is the safest default if you have not decided the licensing model yet. You can make it public and add a license later.
